not edited by hand. Every opcode of NVIDIA's instruction-set table for the target's family
(CUDA Binary Utilities v13.5, §4.3), judged on the compiled listings for the target: the
test fixtures, the differential kernels and cuda-samples, compiled for it. Semantics: ✓ every
form in those listings is defined (`NV.SASS.decode`), ✗ one is not, · no listing contains
the opcode (NVIDIA's table is the family's: legacy names no longer compiled, data-center
opcodes, forms of PTX the corpus does not use). Timing: the target's part has a class for
the first form seen (or the bare opcode). Texture and surface opcodes beyond the forms
`decodeTex` lists are outside the model.
